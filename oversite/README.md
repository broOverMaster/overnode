# `oversite` микросервис OverNode

`oversite` — сервис локального сайта. Его прикладные обязанности, внешний API и конфигурация пока не определены; текущая программа служит минимальной проверкой сборки и запуска.

## Локальный запуск

Из корня проекта:

```sh
go run ./oversite/cmd/oversite
```

Или после сборки:

```sh
make build
.local/bin/oversite
```

## Контейнерный образ

Образ собирается из корня репозитория командой:

```sh
docker build -f oversite/Dockerfile .
```

Dockerfile использует `common` и `oversite`, создавая для них временный `go.work` непосредственно внутри build-stage. Исходники `overgate` в этот образ не попадают.

В итоговом образе используется непривилегированный пользователь `65532:65532`. Пока процесс выводит сообщение и завершается, поэтому контейнер не является постоянно работающим сервисом.

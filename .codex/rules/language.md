## Language policy

- Use Russian for project documentation, source comments, docstrings, and other human-facing project prose.
- Use English for runtime logs, errors, command help, and console output.
- Use English for commit messages, `AGENTS.md`, and agent context (`.codex/`).
- Keep identifiers and technical terms idiomatic for the language or interface.
- If the user uses an inaccurate or unclear term, propose a more precise replacement instead of silently reusing it.

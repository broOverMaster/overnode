# `overgate` микросервис OverNode

`overgate` — сервис-шлюз проекта. Его прикладные обязанности, внешние маршруты и конфигурация пока не определены; текущая программа служит минимальной проверкой сборки и запуска.

## Локальный запуск

Из корня проекта:

```sh
go run ./overgate/cmd/overgate
```

Или после сборки:

```sh
make build
.local/bin/overgate
```

## Контейнерный образ

Образ собирается из корня репозитория командой:

```sh
docker build -f overgate/Dockerfile .
```

Dockerfile использует `common` и `overgate`, создавая для них временный `go.work` непосредственно внутри build-stage. Исходники `oversite` в этот образ не попадают.

В итоговом образе используется непривилегированный пользователь `65532:65532`. Пока процесс выводит сообщение и завершается, поэтому контейнер не является постоянно работающим сервисом.

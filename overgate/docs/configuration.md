# Конфигурация overgate

Параметры сетевого резолвера имеют префикс `network`:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `network.local_key` | нет | 32-байтовый seed Ed25519 в виде 64 hex-символов. Имеет приоритет над `network.local_key_path`. |
| `network.local_key_path` | нет | Путь к PEM-файлу Ed25519; используется, если `network.local_key` не задан. |
| `network.overlay_hosts_path` | пусто | Необязательный путь к файлу имён overlay. |

Должен быть задан хотя бы один из `network.local_key` и
`network.local_key_path`. PEM-файл принимает стандартный PKCS#8-блок `PRIVATE
KEY` с Ed25519-ключом или OpenSSH-блок `OPENSSH PRIVATE KEY`.

Файл `overlay.hosts` использует формат `/etc/hosts`, но вместо IP содержит
публичный ключ:

```text
<public-key-hex> <name> [<alias> ...] # комментарий
```

Пустые строки и комментарии разрешены. Имена должны соответствовать правилам
DNS. Публичный ключ и имена в файле проверяются при запуске; ошибка файла
останавливает сервис.

Параметры HTTP-прокси имеют префикс `proxyf`:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `proxyf.listen_on` | `:2080` | TCP-адрес HTTP forward proxy. |
| `proxyf.http_proxy` | пусто | Upstream HTTP proxy `host:port` для internet. |
| `proxyf.yggstack` | пусто | SOCKS5-адрес Yggstack `host:port`. |
| `proxyf.local_site` | пусто | Локальный HTTP backend `host:port`. |

Для `http_proxy`, `yggstack` и `local_site` схема `http://` не указывается.
Порт обязателен; IPv6 записывается как `[::1]:1080`. Credentials, путь, query и
fragment запрещены. У обычного HTTP назначения порт по умолчанию `80`.

Входящий компонент настраивается отдельно:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `httpin.listen_on` | пусто | Адрес входящего HTTP listener; пустое значение отключает его. |
| `httpin.local_site` | пусто | Фиксированный backend; обязателен при включённом listener. |

Значения загружаются общим конфигурационным пакетом в порядке приоритета CLI,
переменные окружения, файл и значения по умолчанию. Например:

```sh
PROXYF__LISTEN_ON=127.0.0.1:2080
PROXYF__YGGSTACK=stack:1080
```

Файл конфигурации overgate должен содержать только его параметры; ключи
`httpd.*` относятся к oversite и строгим загрузчиком не принимаются.

При инициализации адреса проверяются до запуска сервисов. Ошибка конфигурации
завершает процесс с кодом 1.

# Overlay

Пакет преобразует публичный ключ Ed25519 узла Yggdrasil в его IPv6-адрес по
правилам Yggdrasil.

`PublicKey2Address` принимает ровно 32 байта публичного ключа. `NormalizeAddress`
принимает нормализованное имя `<hex_public_key>.ygg` или
`<hex_public_key>.overspace`: суффикс в нижнем регистре, без завершающей точки.
При ошибке обе функции возвращают нулевой, невалидный `netip.Addr` и ошибку.

# config

Загружает конфигурацию с приоритетом аргументы командной строки → переменные окружения →
файл TOML/YAML/JSON → значения по умолчанию. Неизвестные поля файла и поля, которые
нельзя декодировать в переданную структуру, отклоняются.

Каждый компонент объявляет свои внешние параметры через `schema.Field`, а приложение
собирает их в одну структуру. Передавайте все поля в `Load`: загрузчик сам проверит
дубликаты и неоднозначные имена.

```go
type Config struct {
	Logging logging.Config `mapstructure:"logging"`
	HTTPD   httpd.Config   `mapstructure:"httpd"`
}

func Schema() []schema.Field {
	return append(logging.Schema(), httpd.Schema()...)
}

var configuration Config
err := config.Load(args, stdout, &configuration, config.Options{
	Command:     "overnode",
	Description: "OverNode node",
	Fields:      Schema(),
})
if errors.Is(err, config.ErrHelp) {
	return nil // справка уже напечатана; завершить процесс с кодом 0
}
if err != nil {
	return err
}
```

Путь ключа и `mapstructure`-теги структуры должны совпадать: например,
`logging.level` декодируется в поле `Logging.Level`. Для параметров, специфичных
для компонента, после `Load` вызовите его `Validate`, если загрузчик не делает это
косвенно при создании компонента.

Точка в имени ключа для окружения заменяется на `__`: `logging.level` соответствует
`LOGGING__LEVEL`. Для `[]string` значение из окружения задаётся через запятую;
флаг можно передавать повторно. Например: `LOGGING__TAGS=api,public` и
`--logging.tags=api --logging.tags=public`.

Строковые поля, чьи `mapstructure`-теги оканчиваются на `*_path`, приводятся к
абсолютным путям относительно файла конфигурации; без файла базой служит текущий
рабочий каталог. Это не проверка существования и не ограничение доступа к файловой
системе. Загрузка не атомарна: всегда загружайте в новую структуру. Горячая
перезагрузка не поддерживается.

Загрузчик добавляет флаги `--config <файл>` и `-h`/`--help`, поэтому ключи `config`
и `help` зарезервированы. Формат файла определяется расширением. При `--help`
справка печатается в переданный writer и возвращается `ErrHelp`: вызывающий код
обязан завершить процесс успешно.

Подробности определения полей: [schema](schema/README.md).

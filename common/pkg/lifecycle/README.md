# Lifecycle

Пакет определяет контракт `LifeCycle` для сервисов, выполняемых до отмены
контекста, и координирует их совместную работу.

`Start` запускает зарегистрированные сервисы с дочерним контекстом. `Group.Wait`
после завершения первого сервиса отменяет этот контекст, ожидает остальные и
возвращает объединённую ошибку. Отмена дочернего контекста не отменяет контекст
вызывающей стороны. Пустая группа завершается немедленно.

Вызывайте `Wait` ровно один раз после `Start`; срез, передаваемый `Start`, должен
содержать только ненулевые сервисы.

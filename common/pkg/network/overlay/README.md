# Overlay

Пакет разрешает полные имена вида `Name.overspace` в 32-байтовые публичные
ключи Ed25519. Имя `local.overspace` всегда разрешается в публичный ключ,
переданный при создании резолвера. Остальные имена берутся из hosts-файла.

Формат файла аналогичен `/etc/hosts`, но вместо IP-адреса используется
публичный ключ в виде 64 hex-символов:

```text
<public-key-hex> <name> [<alias> ...] # optional comment
```

Пустые строки и комментарии разрешены. Имена должны соответствовать правилам
DNS и не должны включать суффикс `.overspace`.

# Ed25519

Пакет проверяет и преобразует ключи Ed25519.

Seed ноды принимает ровно 32 байта в виде 64 hex-символов. Из seed можно
получить полный приватный ключ и публичный ключ. Публичный ключ также можно
декодировать из 64 hex-символов и кодировать обратно в lowercase hex.

Приватный ключ из PEM загружается в форматах PKCS#8 (`PRIVATE KEY`) и OpenSSH
(`OPENSSH PRIVATE KEY`).

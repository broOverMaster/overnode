# Crypto

Пакет предоставляет публичный API для загрузки и преобразования ключей Ed25519.

Ключ ноды принимает seed (64 hex-символа) или полный приватный ключ Ed25519
(128 hex-символов). `KeyFromHex` возвращает приватный ключ, а `PubFromHex` —
публичный ключ. Публичный ключ также можно декодировать из 64 hex-символов и
кодировать обратно в lowercase hex.

Приватный ключ из PEM загружается в форматах PKCS#8 (`PRIVATE KEY`) и OpenSSH
(`OPENSSH PRIVATE KEY`).

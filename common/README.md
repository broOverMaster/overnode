# Общие пакеты OverNode

Этот модуль предназначен для библиотек, используемых несколькими сервисами проекта: моделей предметной области, клиентов инфраструктуры, общих ошибок, утилит и контрактов. Добавляйте сюда только код с действительно несколькими потребителями; код, относящийся к одному сервису, остаётся рядом с этим сервисом.

## Пакеты

- [`pkg/config`](pkg/config/README.md) — загрузка конфигурации из аргументов командной строки, переменных окружения, файла и значений по умолчанию.
- [`pkg/config/schema`](pkg/config/schema/README.md) — описание внешних параметров конфигурации, используемое загрузчиком и компонентами.
- [`pkg/logging`](pkg/logging/README.md) — создание структурированного `slog.Logger` и его параметры конфигурации.

Импорт общего пакета из сервиса имеет вид:

```go
import "overnode/common/pkg/<package>"
```

Локальная разработка работает через корневой `go.work`. При контейнерной сборке каждого сервиса `common` подключается во временный workspace build-stage.

# Общие пакеты OverNode

Этот модуль предназначен для библиотек, используемых несколькими сервисами проекта: моделей предметной области, клиентов инфраструктуры, общих ошибок, утилит и контрактов.

Сейчас модуль не содержит Go-пакетов. Добавляйте сюда только код с действительно несколькими потребителями; код, относящийся к одному сервису, остаётся рядом с этим сервисом.

Импорт общего пакета из сервиса имеет вид:

```go
import "overnode/common/<package>"
```

Локальная разработка работает через корневой `go.work`. При контейнерной сборке каждого сервиса `common` подключается во временный workspace build-stage.
